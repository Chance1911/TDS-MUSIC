# TDS-MUSIC

Target-Dominant Support-Selected MUSIC (TDS-MUSIC) is a wideband direction-of-arrival estimator for UAV RF sensing under structured interference. The method first selects target-dominant time-frequency support and then estimates spatial covariance only from the retained bins before applying 2-D wideband MUSIC. A pooled-covariance variant, TDS-MUSIC-Fast, is included for runtime-sensitive evaluation.

## Repository Scope

This repository contains the method implementation and verification code used for the paper:

- `src/tds_music/`: installable Python package for simulation, array geometry, support selection, covariance construction, MUSIC search, metrics, and optional learned TF evidence extraction.
- `scripts/`: command-line entry points for TF512 simulation, TFI dataset rendering, TFI classifier training/evaluation, TF support construction, support-selected SCM construction, TDS-MUSIC evaluation, and regression checks.
- `tests/`: unit and smoke tests for the estimator.
- `data/`: placeholder for user-provided datasets or result tables.
- `configs/`: default geometry and evaluation settings.
- `weights/`: checkpoint placement notes.

Raw multichannel field RF recordings, generated simulation datasets, trained checkpoints, and paper result tables are not included in this upload-ready repository.

## Installation

The core estimator requires NumPy. H5 loading requires `h5py`. The learned TF evidence front end additionally requires PyTorch and torchvision.

```bash
python -m pip install -e .
```

For the optional learned front end:

```bash
python -m pip install -r requirements-optional-torch.txt
```

## Quick Checks

Run the algorithm tests:

```bash
python -m unittest discover -s tests
```

The repository also includes scripts for result-table checks. These require external result CSV/JSON files generated by the experiment pipeline:

```bash
python scripts/check_regression.py
python scripts/evaluate_field.py
```

## Simulation Workflow

Generate signal-plus-noise TF512 observations:

```bash
python scripts/generate_awgn_tf512.py --config configs/simulation_awgn_tf512.yaml
```

Generate controlled-interference TF512 observations:

```bash
python scripts/generate_interference_tf512.py --config configs/simulation_interference_tf512.yaml
```

Render generated H5 observations as a TFI ImageFolder dataset:

```bash
python scripts/build_tfi_imagefolder.py \
  --h5_root outputs/tf512_h5 \
  --out_dir outputs/tfi_imagefolder \
  --mode mean_mag
```

## Minimal Estimator Example

```python
import numpy as np

from tds_music.arrays.geometry import make_uca_positions
from tds_music.estimation.pipeline import estimate_tds_music
from tds_music.estimation.support import threshold_support

positions = make_uca_positions(num_sensors=8, radius_m=0.14)
az_grid = np.arange(0.0, 360.0, 1.0)
el_grid = np.arange(-30.0, 31.0, 1.0)

# x_tf: complex array with shape [time, frequency, sensor]
# freqs_hz: array with shape [frequency]
# reliability: target-dominant TF reliability map with shape [time, frequency]
support = threshold_support(reliability, threshold=0.5, min_bins=64)
estimate = estimate_tds_music(x_tf, freqs_hz, support, positions, az_grid, el_grid)
print(estimate.az_deg, estimate.el_deg)
```
